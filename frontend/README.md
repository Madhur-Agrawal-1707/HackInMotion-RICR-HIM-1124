# HackInMotion Frontend

This is the React + TypeScript frontend for the HackInMotion application, built with Vite and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build the app
- `npm run preview` — preview the production build
- `npm run test` — run the Vitest test suite
- `npm run lint` — run the workspace linter

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Query
- Vitest
